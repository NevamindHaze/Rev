What's new

• Sync over Wi-Fi: at home, Rev now syncs with Anki on your computer directly, in a second or two instead of waiting for iCloud. In Anki, open Tools → Rev Sync Wi-Fi…, switch it on, and type the computer and pairing code it shows into Rev's Settings → Sync over Wi-Fi. The first time, allow Rev to use the local network.
• When your iPhone isn't on the same Wi-Fi, or Anki is closed, Rev syncs through iCloud as before, by itself. Settings tells you which way the last sync went.
• Needs the updated Rev Sync add-on in Anki (copy the new anki-addon/rev_sync folder into Anki's addons21 folder and restart Anki).
